## What this branch implements

- FastMCP weather server deployed as a Databricks App.
- Separate Open-Meteo adapter module for all HTTP/parsing logic.
- Required MCP capabilities:
  - `get_current_weather`
  - `get_forecast`
  - `get_travel_recommendation`
- Stretch capability:
  - `compare_weather`
- Agent Bricks system prompt, tool list, guardrails, and demo prompts.
